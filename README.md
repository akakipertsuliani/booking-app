# Booking App

A modern appointment booking web application built for small businesses such as barbers, salons, dentists, and similar services.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Authentication
- Vercel

## Features

- Customer appointment booking
- Customer accounts
- Business/admin dashboard
- Appointment management
- Available time slots
- Email confirmations
- Responsive mobile-friendly design
